# Country versions

Airokrasi is a universal framework. Each nation can use it to write **its own version**: its own constitution text, laws, figures and institutions, in its own language and its own words (founder inputs K24, K27).

- One folder per country: `countries/<country>/` (lower-case, ASCII, e.g. `turkiye`, `germany`, `brazil`).
- Write in the country's own language. Add a short English summary (`SUMMARY.md`) so that others can follow.
- A country version may adapt anything below the Declaration (Constitution, laws, regulations, institutions, figures). It may **not** fall below the Declaration ([DECLARATION.md](../DECLARATION.md)).
- Every article carries a rationale footnote (purpose, reason, debate summary, source), as in the rest of the project.
- Name the concepts in your own language's natural words; the shared concept definitions are in the concept registry (`docs/tartismalar/2026-11-09-terimler/kavram-kaydi.md`).
