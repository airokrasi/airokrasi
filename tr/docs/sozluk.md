# Sözlük

| Terim | Tanım |
|---|---|
| **Airokrasi** | Yapay zekâ ajanlarının yönetim süreçlerini yürüttüğü, egemenliğin insanlarda kaldığı yönetim modeli. |
| **Ajan** | Belirli bir görev ve yetki kapsamında özerk olarak çalışan yapay zekâ sistemi. |
| **Üst norm** | Evrensel insan hakları metni; tüm anayasa ve yasaların uymak zorunda olduğu en üst hukuk kuralı. |
| **Yasama ajanı** | Yasa taslağı ve etki analizi hazırlayan ajan. |
| **Yürütme ajanı** | Yasaları uygulayan, kamu hizmetlerini yürüten ajan. |
| **Yargı ajanı** | Uyuşmazlıkları inceleyen ve hukuka uygunluk denetimi yapan ajan. |
| **Yurttaş meclisi** | Kurayla seçilen, ajan önerilerini müzakere edip onaylayan yurttaş grubu. |
| **İnsan onay eşiği** | Bir ajan kararının insan onayı gerektirdiği sınır. |
| **Kırmızı takım ajanı** | Sistemi açıklar ve kötüye kullanım için sürekli test eden bağımsız ajan. |
| **Karar kaydı (KK)** | Proje içinde alınan bir tasarım kararını, gerekçesini ve alternatiflerini belgeleyen dosya. |
