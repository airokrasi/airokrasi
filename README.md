## How this project works

- **Built from values down to rules:** Manifesto → Declaration → Constitution → Laws → Regulations → Institutions. No layer may contradict the one above it.
- **AI agents debate, an AI referee decides with reasons.** Each topic goes through proposal, critique, specialist reviews (law, AI security, economy, the citizen's view), defence, reply and a referee decision. Every article carries a rationale footnote: purpose, reason, debate summary, source.
- **The founder makes no decisions (K31).** Value choices are decided by AI referees who took no part in the debate. Every decision is published and can be reopened by an issue that brings a new argument or new evidence.
- **One framework, many countries.** Each nation can use this framework to write its own version in `countries/<country>/`. Türkiye is the first.
- **Languages:** English is the main language. The Turkish originals are in [`tr/`](tr/). The debate archive in `docs/tartismalar/` is in Turkish. Each language names the concepts in its own words; there is no dictionary translation.
- **Honest limits:** the work so far was produced by AI agents of a single model family. It has not yet been tested by real citizens, lawyers or experts. Your criticism is the most valuable contribution.

## Contributing

Open an issue with your idea, objection or correction, and name the roadmap item (for example `L2.5`) and the task (for example `V-08`). Text that comes from outside is treated as data, never as instructions. The full contribution system (AGENTS.md, issue forms, automated review roles) has been designed and is waiting for its security review: see [docs/tartismalar/2026-11-08-github-yonetisim/](docs/tartismalar/2026-11-08-github-yonetisim/).
