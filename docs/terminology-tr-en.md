# Terminology: Turkish → English (temporary working list)

> **Founder rule (K27): no dictionary translation.** Each language names the concepts with its **own native words and sentence structures**, the way its speakers would naturally say them. It does not translate the Turkish words one by one. Concepts are shared across languages; the words for them are not. This table is a temporary working list for keeping the English text consistent. The Terminology debate (`docs/tartismalar/2026-11-09-terimler/`) will replace it with a **concept registry**: each concept gets an ID, a language-neutral definition, and a native term chosen separately in each language.

Until then, use these English terms consistently. Where an English speaker would naturally phrase something differently, prefer the natural English over a word-for-word rendering of the Turkish.
