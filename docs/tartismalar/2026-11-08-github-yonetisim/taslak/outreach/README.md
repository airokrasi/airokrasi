# Outreach kit (K30)

Ready-to-adapt texts for telling people about Airokrasi. **These are drafts for a person to read, edit and post under their own name.** Nothing in this repository posts to any outside platform.

Repository: https://github.com/airokrasi/airokrasi (How to contribute: CONTRIBUTING.md, "Ways to help")

## The honesty limits (rules, with reasons)

1. **A person approves and posts every outside message.** The weekly digest workflow writes a share-ready summary, but it only posts inside GitHub (Discussions). *Why:* the project's own principle is that people keep the last word; a project about consent should not recruit without it. Platform rules also differ per site and change; a person can read them, a script cannot be trusted to.
2. **No mass automation.** No bots that post, reply, follow, like or message. One thoughtful post per platform, then answer people yourself. *Why:* it is spam by any platform's rules, and it would make the project look like what it argues against.
3. **No fake accounts, no sock puppets, no bought or traded engagement, no asking friends to upvote.** *Why:* vote manipulation is banned on the platforms below, and the project's own rule is that votes and reactions are never arguments.
4. **Disclose who you are.** Say you are involved in the project. If an AI helped write the post, say so where the platform allows it.
5. **Do not copy the same post across accounts or communities.** Adapt it to each place and read that place's rules first.
6. **Never promise what the project cannot do.** It is a concept in documents, not a government product. Say that decisions are machine-made and open to challenge.
7. **Honour opt-outs.** If an academic or an organisation does not want mail, do not write again.

## Platform notes (checked while preparing this kit; rules change, so re-read them)

- **Hacker News.** The guidelines ask that comments and submissions be human-written ("do not post generated or AI-edited comments"), forbid soliciting upvotes, and a *Show HN* must be something people can run or try. This project is documents, so a plain link submission with a factual title is the honest form, and the text must be written by the person, not pasted from this kit. The file `hackernews.md` therefore holds facts only, not a post.
- **X (Twitter).** The rules forbid posting duplicative content across multiple accounts and unsolicited automated replies. One account, one post, no automated replies.
- **Reddit.** Self-promotion limits are mostly set by each community's rules plus the site-wide content policy against spam and vote manipulation. Read each subreddit's rules, ask the moderators if unsure, participate before you promote.
- **LinkedIn.** Not verified from here (the help pages were not reachable). Assume professional-use and spam rules apply; read them before posting.
- **E-mail to people you do not know.** Keep it short, personal, with one clear invitation, an easy way to say no, and your real name. Check the anti-spam law that applies to the recipient (for example GDPR and national e-privacy rules in Europe). Unsolicited bulk mail is not allowed.
